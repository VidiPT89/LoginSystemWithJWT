## 📝 About Section

Na página principal do repositório, na seção **About**, adicione a seguinte descrição:

```
Modern secure authentication system with JWT tokens, bcrypt hashing, password reset via email 
and bilingual UI (PT/EN) — built with Express.js, PostgreSQL and Nodemailer.
```

**Onde encontrar:**
1. Vá para o repositório
2. Clique em ⚙️ **Settings**
3. Na seção **About**, altere a descrição
4. Salve as alterações

## 🔐 Secrets & Security

Para variáveis sensíveis (API keys, tokens):

1. **Nunca** fazer commit de `.env` com dados reais
2. Incluir `.env.example` com placeholders
3. Use GitHub Secrets para CI/CD
4. Documente em `SECURITY.md` se necessário
