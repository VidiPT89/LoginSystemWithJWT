🚀 PRÓXIMOS PASSOS:

1. CONFIGURAR POSTGRESQL
   ┌─────────────────────────────────────────────────────────┐
   │ # macOS                                                 │
   │ brew install postgresql                                 │
   │ brew services start postgresql                           │
   │                                                         │
   │ # Linux (Ubuntu)                                        │
   │ sudo apt install postgresql                              │
   │ sudo service postgresql start                            │
   │                                                         │
   │ # Criar banco de dados                                  │
   │ psql -U postgres                                         │
   │ CREATE DATABASE login_system;                            │
   │ \q                                                      │
   └─────────────────────────────────────────────────────────┘

2. CONFIGURAR VARIÁVEIS DE AMBIENTE
   ┌─────────────────────────────────────────────────────────┐
   │ O arquivo .env já foi criado com valores padrão.       │
   │                                                         │
   │ Se quiser customizar:                                   │
   │ nano .env                                               │
   │                                                         │
   │ Campos importantes:                                     │
   │ - DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD      │
   │ - JWT_SECRET (mude em produção!)                        │
   │ - EMAIL_* (para reset de senha)                        │
   └─────────────────────────────────────────────────────────┘

3. CRIAR TABELAS NO BANCO DE DADOS
   ┌─────────────────────────────────────────────────────────┐
   │ npm run migrate                                          │
   │                                                         │
   │ Esperado: ✅ Tabela de usuários criada com sucesso!    │
   └─────────────────────────────────────────────────────────┘

4. INICIAR SERVIDOR EM DESENVOLVIMENTO
   ┌─────────────────────────────────────────────────────────┐
   │ npm run dev                                              │
   │                                                         │
   │ O servidor iniciará em: http://localhost:3000          │
   │ Mudanças no código recarregam automaticamente           │
   └─────────────────────────────────────────────────────────┘

5. TESTAR A API
   ┌─────────────────────────────────────────────────────────┐
   │ # Registrar novo usuário                               │
   │ curl -X POST http://localhost:3000/api/auth/register \  │
   │   -H "Content-Type: application/json" \                │
   │   -d '{                                                 │
   │     "email": "teste@exemplo.com",                       │
   │     "username": "usuario_teste",                        │
   │     "password": "senha123",                             │
   │     "passwordConfirm": "senha123"                       │
   │   }'                                                    │
   │                                                         │
   │ # Fazer login                                           │
   │ curl -X POST http://localhost:3000/api/auth/login \    │
   │   -H "Content-Type: application/json" \                │
   │   -d '{                                                 │
   │     "email": "teste@exemplo.com",                       │
   │     "password": "senha123"                              │
   │   }'                                                    │
   │                                                         │
   │ # Acessar perfil protegido                             │
   │ curl -X GET http://localhost:3000/api/auth/profile \   │
   │   -H "Authorization: Bearer SEU_TOKEN_AQUI"             │
   └─────────────────────────────────────────────────────────┘

📚 ENDPOINTS DA API:

PUBLIC ENDPOINTS (sem autenticação):
  POST   /api/auth/register                    - Registrar novo usuário
  POST   /api/auth/login                       - Fazer login
  POST   /api/auth/refresh-token               - Renovar access token
  POST   /api/auth/request-password-reset      - Solicitar reset de senha
  POST   /api/auth/reset-password              - Resetar senha

PROTECTED ENDPOINTS (requerem JWT):
  GET    /api/auth/profile                     - Obter dados do usuário

HEALTH CHECK:
  GET    /api/health                           - Verificar status do servidor

🐛 TROUBLESHOOTING RÁPIDO:

Erro: "ECONNREFUSED" (Banco de dados não conecta)
→ brew services start postgresql

Erro: "database does not exist"
→ psql -U postgres
  CREATE DATABASE login_system;

Erro: "Port 3000 already in use"
→ Mude PORT no .env ou mate o processo:
  lsof -i :3000 && kill -9 <PID>

Erro: "Email não está sendo enviado"
→ Configure App Password do Google em:
  https://myaccount.google.com/apppasswords
